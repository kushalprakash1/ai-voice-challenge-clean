# VoiceProbe — Call Evidence

This directory contains the ten calls used for the submission and Loom
walkthrough.

Every call folder contains:

- `call.mp3` — mixed recording containing both sides of the call
- `transcript.txt` — timestamped transcript containing `AGENT` and `PATIENT`
- `README.md` — context plus direct audio/transcript links

Calls 10–7 are development evidence. Calls 6–1 are the final behavioral
cases. The numbering is presentation order rather than the original execution
order; see [`docs/iteration.md`](../../docs/iteration.md).

## Submission requirement

All ten calls provide both:

1. a full mixed audio recording in MP3 format; and
2. a timestamped transcript containing both sides of the conversation.

The development calls are included because they show the real iteration path
that led to the final behavioral cases rather than presenting only polished
results.
